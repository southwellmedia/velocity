# Agent Guide

Instructions for AI coding agents (Claude Code, Codex, Cursor, etc.) working in this project.

This project is built on [Velocity](https://github.com/southwellmedia/velocity). Read and follow @.agents/velocity.md before changing code. Velocity upgrades keep that file current, so put your own rules here instead.

Step-by-step skills for common tasks are in `.agents/skills/`: `velocity-start-site` (set up or rebuild the whole site from a brief), `velocity-add-page`, `velocity-add-component`, `velocity-add-content`, `velocity-add-locale`, `velocity-connect-forms` and `velocity-rebrand`. If your tool doesn't load skills automatically, read the matching `SKILL.md` before starting the task. Before changing the site's look, read `.agents/design.md`: the design is yours, Velocity only asks for a few things that keep it working.
