# Bienvenido a Velocity

Velocity es una plantilla lista para producción creada con **Astro 7** y **Tailwind CSS v4**. Te ayuda a crear sitios rápidos, atractivos y accesibles con muy poca configuración.

Este artículo es la traducción de `src/content/blog/en/welcome-to-velocity.mdx`. Las traducciones comparten el nombre de archivo en la carpeta de cada idioma, y Velocity las enlaza automáticamente con `hreflang` y el selector de idioma.
